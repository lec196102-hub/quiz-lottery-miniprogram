# 答题抽奖小程序 — 低保真线框图与交互原型说明

> 配套文档：《PRD-答题抽奖小程序.md》（`docs/`）
> 可交互原型：`prototype/index.html`（单文件，浏览器打开即可点击跳转）
> 数据层：`prototype/test_data.js`（静态数据）、`prototype/data.js`（引用与抽奖引擎）

## 1. 文档目的与范围

依据 PRD 提炼每个模块的核心功能、关键用户流程与界面结构（列表/详情/配置/结果页），输出低保真线框图与可交互原型，覆盖主要操作路径及四类典型状态：**空状态、加载中、报错、成功**。

> 关于画布工具：本环境无 Figma / Sketch 连接，等价交付为单文件 HTML 可交互原型（`index.html`），页面层级、跳转关系与四态标注在原型内以真实可点击组件实现；本文档以框模型（box model）描述各页面结构与关键组件，作为原型的配套设计说明，便于评审时对照。

## 2. 核心功能模块（提炼自 PRD §3）

| 端 | 模块 | 核心职责 |
|---|---|---|
| 参与者端 | 活动入口 | 扫码/链接进入，展示活动信息与奖品池 |
| 参与者端 | 身份登记 | 采集姓名 + 工号，校验唯一性 |
| 参与者端 | 随机答题 | 每轮从 150 题随机抽 5 题，逐题作答 |
| 参与者端 | 通关判定 | 5 题答对 ≥3 题即通关 |
| 参与者端 | 资格抽奖 | 通关者获得 1 次抽奖资格，转盘抽奖 |
| 参与者端 | 结果展示 | 显示得奖等级 / 谢谢参与 |
| 参与者端 | 我的奖品 | 展示本人抽奖资格与已得奖品 |
| 管理后台 | 账号鉴权 | 管理员登录，不返回密码字段 |
| 管理后台 | 数据看板 | 参与/通关/中奖实时统计 |
| 管理后台 | 题库导入 | 批量导入选择题（含去重/校验） |
| 管理后台 | 获奖名单 | 查询、筛选、导出 CSV（含时间） |
| 管理后台 | 奖品池监控 | 各等级剩余/总量监控 |

## 3. 信息架构（IA）

```
答题抽奖小程序
├─ 参与者端（小程序，扫码/链接进入）
│   ├─ 首页 / 活动介绍          home
│   ├─ 身份登记                 register
│   ├─ 答题页                   quiz            （5 题逐页，进度条）
│   ├─ 答题结果                 quiz-result     （通关 / 未通关）
│   ├─ 抽奖页                   lottery         （转盘 + 资格校验）
│   ├─ 抽奖结果                 lottery-result  （X 等奖 / 谢谢参与）
│   └─ 我的奖品                 mine
└─ 管理后台（PC，账号登录）
    ├─ 登录                     admin-login
    ├─ 数据看板                 admin-dashboard
    ├─ 题库导入                 admin-questions
    ├─ 获奖名单                 admin-winners
    └─ 奖品池监控               admin-prizes
```

## 4. 页面层级与跳转关系

| 起点 | 目标 | 触发动作 | 条件 / 守卫 |
|---|---|---|---|
| home | register | 点「开始答题」 | 无 |
| register | quiz | 提交姓名+工号且校验通过 | 姓名/工号非空且未存在 |
| register | home | 点返回 | — |
| quiz | quiz（下一题） | 点「下一题」 | 已选答案 |
| quiz | quiz-result | 点「交卷」 | 5 题作答完成 |
| quiz-result | lottery | 点「去抽奖」 | 通关（correct≥3） |
| quiz-result | quiz | 点「再答一次」 | 未通关（仅答题不限次） |
| quiz-result | home | 点返回 | — |
| lottery | lottery-result | 转盘停止 | 已通关且本次未抽过 |
| lottery | home | 点返回 / 无资格提示 | 未通关或已抽过 |
| lottery-result | mine | 点「查看我的奖品」 | — |
| lottery-result | home | 点返回 | — |
| mine | lottery | 点「去抽奖」 | 有资格且未抽 |
| mine | home | 点返回 | — |
| admin-login | admin-dashboard | 登录成功 | 账号密码正确 |
| admin-login | admin-login | 登录失败 | 密码错误 → 报错态 |
| admin-dashboard | admin-questions / admin-winners / admin-prizes | 侧栏导航 | 已登录 |
| admin-* | admin-login | 退出登录 | — |

## 5. 逐页线框（框模型 + 组件说明）

### 5.1 参与者端

#### 5.1.1 首页 / 活动介绍（home）
```
┌─────────────────────────┐
│  [返回]   活动介绍    [≡] │  ← 顶部导航栏
├─────────────────────────┤
│   活动大标题              │
│   副标题 · 活动时间区间    │
│  ┌───────────────────┐  │
│  │ 活动规则（卡片）    │  │
│  │ · 答对 3 题通关     │  │
│  │ · 每人抽奖 1 次     │  │
│  │ · 中奖率 25%        │  │
│  └───────────────────┘  │
│   奖品池一览             │  ← 三级进度条
│   一等 5 / 二等 50 / 三等 100 │
│  ┌───────────────────┐  │
│  │   [ 开始答题 ]     │  │  ← 主按钮（primary, block）
│  └───────────────────┘  │
└─────────────────────────┘
```
- **关键组件**：活动标题、规则卡片、奖品池进度条、主行动按钮。
- **状态**：成功态（正常展示）；加载中（首次拉取活动配置时骨架屏）；报错态（活动已结束 → 提示「活动已结束」）。

#### 5.1.2 身份登记（register）
```
┌─────────────────────────┐
│  [返回]   身份登记    [ ] │
├─────────────────────────┤
│  姓名  [___________]     │  ← 输入框
│  工号  [___________]     │
│  ┌───────────────────┐  │
│  │ [ 提交并进入答题 ] │  │  ← 主按钮
│  └───────────────────┘  │
│  小字：信息仅用于发奖核对  │
└─────────────────────────┘
```
- **关键组件**：姓名输入框、工号输入框、提交按钮、错误提示行。
- **状态**：报错态（姓名/工号空 → 行内红字；工号已存在 → 「该工号已参与过抽奖」）；加载中（提交时按钮转圈）；成功态（跳 quiz）。

#### 5.1.3 答题页（quiz）
```
┌─────────────────────────┐
│  [返回]   答题 (2/5)  [ ] │  ← 进度 (i/5)
├─────────────────────────┤
│  ▓▓▓▓▓░░░░  40%          │  ← 进度条
│  Q2. 题目文本？           │
│  ○ A. 选项 A              │  ← 单选组（radio card）
│  ○ B. 选项 B              │
│  ○ C. 选项 C              │
│  ○ D. 选项 D              │
│  [上一题]   [下一题/交卷] │  ← 底部双按钮
└─────────────────────────┘
```
- **关键组件**：进度指示、进度条、题号、单选题卡片组、上一题/下一题按钮（末题变「交卷」）。
- **状态**：加载中（抽题时）；报错态（网络异常 → Toast「加载失败，重试」）；成功态（作答实时高亮）。
- **防重抽**：选答案仅更新本地状态，不重新抽题（已在 data.js 中固化本轮 5 题）。

#### 5.1.4 答题结果（quiz-result）
```
┌─────────────────────────┐
│  [返回]   答题结果    [ ] │
├─────────────────────────┤
│   ✅ 通关！答对 4/5       │  ← 通关态
│   您已获得 1 次抽奖资格    │
│  ┌───────────────────┐  │
│  │   [ 去抽奖 ]       │  │
│  └───────────────────┘  │
│  ── 或 ──                │
│   ❌ 未通关 答对 2/5      │  ← 未通关态
│  ┌───────────────────┐  │
│  │   [ 再答一次 ]     │  │
│  └───────────────────┘  │
└─────────────────────────┘
```
- **关键组件**：结果图标、正确数、行动按钮（去抽奖 / 再答一次）。
- **状态**：成功态（两种结果分支）；空状态（无答题记录 → 引导去登记）。

#### 5.1.5 抽奖页（lottery）
```
┌─────────────────────────┐
│  [返回]   幸运抽奖    [ ] │
├─────────────────────────┤
│       ╭───────╮          │
│      │  转 盘  │          │  ← Canvas 转盘（8 扇区）
│       ╰───●───╯          │
│      [  开始抽奖  ]       │  ← 主按钮
│   中奖率 25% · 每人 1 次   │
│   剩余：一5/二50/三100     │
└─────────────────────────┘
```
- **关键组件**：Canvas 转盘、指针、抽奖按钮、概率与剩余提示。
- **状态**：无资格（未通关 → 空状态卡「尚未获得抽奖资格，去答题」）；已抽过（提示「您已参与过抽奖」）；奖品耗尽（提示「奖品已全部送出」）；加载中（转盘旋转动画）；成功态（转出结果跳 lottery-result）。

#### 5.1.6 抽奖结果（lottery-result）
```
┌─────────────────────────┐
│  [返回]   抽奖结果    [ ] │
├─────────────────────────┤
│   🎉 恭喜获得 二等奖！    │  ← 中奖态
│   奖品：XX 充电宝         │
│  ┌───────────────────┐  │
│  │ [ 查看我的奖品 ]   │  │
│  └───────────────────┘  │
│  ── 或 ──                │
│   感谢参与~              │  ← 未中奖态
│   （谢谢参与）            │
└─────────────────────────┘
```
- **关键组件**：中奖等级、奖品名、查看入口 / 感谢文案。
- **状态**：成功态（中奖、未中奖两种）；空状态（无记录引导）。

#### 5.1.7 我的奖品（mine）
```
┌─────────────────────────┐
│  [返回]   我的    [ ]    │
├─────────────────────────┤
│  姓名 / 工号             │
│  抽奖资格：已使用 ✅      │
│  ┌───────────────────┐  │
│  │ 已得奖品：二等奖    │  │  ← 卡片
│  │ 获得时间：...       │  │
│  └───────────────────┘  │
│  （未中奖时显示感谢语）   │
└─────────────────────────┘
```
- **关键组件**：身份摘要、资格徽标、奖品卡片（含时间）。
- **状态**：空状态（未参与 → 引导登记）；未中奖态（已抽未中 → 感谢语）。

## 7. 关键组件库与设计令牌

- **按钮**：`btn`（默认）、`btn primary`（主行动）、`btn block`（整行）、`btn[disabled]`（置灰）。
- **卡片**：`card` 承载片段信息，圆角 + 浅描边。
- **进度条**：答题 `progress`（i/5 + 百分比）；奖品池三级进度。
- **转盘**：Canvas 8 扇区（4 等级 ×2 镜像），指针居中，旋转动画后停在目标扇区。
- **反馈**：`toast`（轻提示，2s 自动消失）、`empty`（空状态组件，含图标/标题/描述/可选行动按钮）。
- **导航**：参与者端 `navbar`（返回 + 标题）；后台 `admin-side` 侧栏 + `admin-head` 标题栏。
- **配色（暗色原型）**：背景 `#1E1E1C`，卡片 `#2A2A28`，主色 `#E0B84C`（金），成功 `#4CAF86`，危险 `#E0584C`，文字 `#D3D1C7`。

> 以上层级、跳转与状态标注与原型 `index.html` 实现一致；如需接入真实后端，仅替换 `data.js` 中模拟 API 为真实请求即可，页面结构与命名保持不变。
